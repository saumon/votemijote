# Vote et Mijote !

Landing page for the "Vote et Mijote !" mobile application, designed to bring serenity back to the dinner table.

![Vote et Mijote Hero Section](assets/logo.png?raw=true "Vote et Mijote Logo")

## 🥘 About the App

Every day, it’s the same question: **"What are we eating?"**

With **Vote et Mijote !**, say goodbye to endless debates.
1.  **Propose**: The cook creates a list of dishes they are happy to prepare.
2.  **Vote**: The rest of the family votes for their favorites.
3.  **Enjoy**: The app reveals the winner instantly.

It's your new meal assistant: simple, fun, and fair.

## 🎨 Features & Design

-   **Colorful Theme**: A vibrant palette (Pink, Yellow, Teal) designed to appeal to families.
-   **Responsive**: Looks great on desktop and mobile devices.
-   **Clean Code**: Built with semantic HTML5, modern CSS3, and lightweight JavaScript.
-   **Animations**: Smooth entrance animations for a dynamic user experience.

## 🛠️ Built With

-   HTML5
-   CSS3 (Variables, Flexbox, Grid)
-   JavaScript (Intersection Observer API)

## 🚀 How to Run

No build step required!

1.  Clone the repository.
2.  Open `index.html` in your web browser.

```bash
git clone https://github.com/saumon/votemijote.git
cd votemijote
# Open index.html
```
